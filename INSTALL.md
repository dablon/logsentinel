# Install scripts for LogSentinel

## Local Install (editable - for development)

### PowerShell
```powershell
.\install-local.ps1
```

### Bash
```bash
chmod +x install-local.sh
./install-local.sh
```

## Global Install (system-wide)

### PowerShell (requires admin)
```powershell
.\install-global.ps1
```

### Bash (requires sudo)
```bash
chmod +x install-global.sh
sudo ./install-global.sh
```

## Uninstall

### PowerShell
```powershell
.\uninstall.ps1
```

### Bash
```bash
sudo ./uninstall.sh
```
